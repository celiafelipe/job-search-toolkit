---
name: job-prepare
description: Prepare a factual role-specific CV, any required cover letter, and proposed exact form answers from observed application constraints and detailed career evidence.
---

Use [the package contract](../../docs/WORKFLOW.md). Work in a fresh isolated context for a selected application; if invoked standalone, an independent reviewer still needs a separate fresh context before transmission. Require the raw posting, selected role, employer form inspection, master CV, relevant detailed career evidence and current user decisions. If the form cannot be inspected, prepare a provisional local draft and mark constraints and answers unknown; do not mark it ready.

Before writing, extract must-haves and search detailed evidence across roles for the most relevant domain, audience, workflow, responsibility, scale and measurable outcomes. Rank the strongest supported matches, including less recent evidence. Record sources and whether each connection is direct, adjacent, unsupported or suggested by the user. Keep ownership, time frame, scope and metric denominators intact. Treat unsourced recollections as leads to confirm; never manufacture or fill gaps.

Copy the master CV into a role folder. Reorder or clarify evidence so the strongest relevant examples appear early. Use the employer's vocabulary where it accurately describes the work. Keep role, employer, date and achievement relationships readable. Prefer specific actions and outcomes over buzzwords and invented metrics; respect language and length constraints without arbitrary page limits. Reuse the base only if its emphasis fits. Do not edit original career sources.

Write a letter only if the application requires it. Use two or three specific evidence-backed connections to the employer’s needs; avoid generic motivation or repeating the CV. Match the actual format/length. For answers, record exact prompts, proposed values, sources, and applicable approval scope. Check dated/qualified facts; leave unsupported optional fields empty and surface unresolved required fields rather than guess.

Use `build-pdf` for each outgoing PDF. Keep the evidence map, sources, build receipts and exact proposed answer set. Hand off the package to an independent reviewer. Stay offline; no form entry, upload, application, policy changes, or tracker updates.
